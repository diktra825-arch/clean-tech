# clean-tech

Indika Saputra - 221011402182

Clean-Tech adalah aplikasi website jasa cleaning service yang dibuat untuk memudahkan pelanggan untuk melakukan pemesanan layanan kebersihan.
Memiliki keunggulan yaitu terdapat diskon untuk member baru, berlangganan, serta 5x pemesanan layanan.

**Fitur Utama**

**Untuk Pelanggan**
- Pemesanan Layanan Secara Online
- Terdapat sistem pemberi diskon secara otomatis
- Pembayaran dengan upload bukti transfer
- Pesanan bisa ditracking statusnya
- Riwayat pemesanan disimpan

**Untuk Admin**
- Dashboard yang memberi informasi keseluruhan secara sederhana
- Manajemen Layanan
- Manajemen User
- Manajemen Diskon
- Memiliki sistem Laporan
